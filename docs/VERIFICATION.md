## 성능 표본

동시에 구동되는 **200개 부품 / 350개 관절**, 고품질 20/10 반복, 240개 물리 스텝(시뮬레이션 2초)을 관리형 Linux Node에서 **약 365ms**에 계산한 표본을 얻었습니다(약 657 step/s). 이는 렌더링을 제외한 특정 CPU 장면의 표본입니다. 실제 Chromebook 하드웨어의 프레임 속도를 측정했다는 뜻은 아닙니다. 대량 접촉이나 더 복잡한 장면에서는 성능이 낮아집니다.

## 프로덕션 빌드와 독립 실행

`npm run build`: TypeScript 엄격 검사와 Vite 프로덕션 빌드 통과. JavaScript와 CSS를 하나의 HTML에 포함합니다. 외부 폰트·API·서버 호출이 없습니다.

개발 환경의 관리형 Chromium은 `file://` 이동을 `ERR_BLOCKED_BY_ADMINISTRATOR` 정책으로 차단합니다. 이 정책을 우회하지 않았습니다. 따라서 이 환경에서 로컬 파일을 직접 더블클릭하여 여는 경로와 실제 Chromebook 기기 검증은 완료했다고 주장하지 않습니다. 동일한 단일 HTML의 정적 제공 및 브라우저 실행을 별도로 검증합니다. 브라우저가 file 저장소를 제한하면 JSON으로 보관하고 정적 웹 배포를 사용하세요.

브라우저 네트워크를 **오프라인**으로 설정하고 빌드된 HTML 전체를 새 문서에 주입하는 독립 실행 검증도 통과했습니다. 실행 후 0.5초 이상의 실제 물리 시간을 진행했고 JavaScript 오류 및 외부 HTTP 요청은 0개였습니다. 이 불투명 출처 문서는 IndexedDB를 허용하지 않으므로 저장 기능은 별도로 실제 HTTP 출처의 브라우저 테스트에서 검증합니다.

GitHub 및 Vercel의 실제 배포/CI 상태는 저장소와 배포 서비스에서 확인합니다. 로컬 테스트 통과를 원격 CI 또는 실기기 통과로 대체하지 않습니다.
