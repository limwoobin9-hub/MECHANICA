# 물리 모델

## 시간·단위·좌표

물리는 Planck의 Box2D 순차 충격량 솔버로 **고정 1/120초** 간격으로 계산합니다. Canvas 렌더링은 별도의 requestAnimationFrame입니다. React에는 약 75ms마다 계측 스냅샷을 전달합니다. SI 단위: m, kg, s, N, N·m, rad/s, J, W. 화면의 +Y는 아래쪽이며 양의 회전은 화면에서 시계방향입니다.

선택 품질의 속도/위치 반복 수는 정밀 20/10, 균형 12/6, 성능 8/4입니다. 1프레임 최대 40개 고정 스텝을 처리합니다. 연산을 따라잡지 못하면 실제 경과 시간 일부를 버리고 과부하를 표시합니다. 물리 dt를 크게 늘려 따라잡지 않습니다. 고배속은 실제 실행 성능에 따라 느려질 수 있습니다.

Box2D의 수치 안정성 상한도 적용됩니다. 한 스텝에서 강체의 회전은 약 π/2 rad 이내로 제한되어 120Hz에서 약 1,800RPM을 넘는 상태는 신뢰할 수 없습니다. 목표·초기 값 및 증속 기어에서 이 범위를 피하세요. 높은 회전 속도에서 세부 충돌을 분석하는 용도가 아닙니다.

## 강체와 관성

- 원형 회전체: `I = m r² / 2`인 균일 원판. 표시되는 구멍/스포크/톱니의 질량 차이는 모델링하지 않습니다.
- 직사각형: `I = m (w²+h²) / 12`.
- 질량과 면밀도를 연결하며 두께를 갖는 3D 밀도 대신 kg/m²를 사용합니다.
- 충돌, Coulomb 접촉 마찰, 반발, 선/각 감쇠는 Box2D로 계산합니다. 작은 물체의 연속 충돌과 Sleep을 사용합니다.
- 기어/풀리/크랭크는 별도 기계 레이어로 서로 충돌하지 않습니다. 기어 사이 힘은 명시적 기어 관절로만 전달됩니다. 연결봉은 기어 레이어를 통과하도록 설정해 평면도에서 다른 깊이의 부품을 나타냅니다. 일반 자유 강체·바퀴·프레임·캠은 접촉으로 상호작용합니다.

## 모터와 저항 부하

회전축에 Box2D RevoluteJoint의 속도 모터를 사용합니다. 각도를 지정하지 않으며 목표 속도까지의 가속은 연결된 전체 관성, 반력과 토크 한계에 의해 결정됩니다.

`목표 ω = RPM × 2π / 60`

`|축 토크| ≤ 최대 설정 토크 × 효율`

모터는 속도를 유지할 토크가 부족하면 감속하거나 정지합니다. 효율은 최대 설정 토크에서 실제 축 토크로의 손실과 입력 동력 산정에 사용합니다. 전압·전류·열·모터별 토크-속도 곡선은 포함하지 않습니다.

회전 저항은 정지 근처의 수치적 진동을 줄이기 위해 `τ_load = -L tanh(ω / 0.08)`로 정규화합니다. 회전 방향을 바꿔도 항상 에너지를 소모합니다. 브레이크는 목표 0인 토크 제한 축 모터입니다. 모터를 끄면 관성이 남아 관성 주행합니다. 즉시 정지하려면 브레이크나 부하를 사용하세요.

선형 액추에이터는 힘 제한 PrismaticJoint 모터입니다. UI의 m/min 입력은 /60하여 m/s로 변환합니다. 일정 힘·토크 발생기는 매 스텝 강체에 실제 힘·토크를 가합니다. 래칫은 역회전 속도를 축 관성에 대응하는 비탄성 충격량으로 0으로 제한합니다. 래칫의 발톱 충돌 및 탄성은 없습니다.

## 기어·동축·랙

피치 반경은 `r = N × module / 2`. 맞물림 전 동일 모듈, 톱니 수, `중심거리 ≈ r₁+r₂`를 검사합니다. 허용 오차는 max(25mm, 중심거리의 1.5%)입니다. 동축 연결은 중심거리 40mm 이내를 요구합니다.

기어 관절은 `q₁ + ratio × q₂ = constant`인 Box2D GearJoint입니다. 외접 기어의 ratio는 `r₂/r₁`이므로 `ω₂ = -(N₁/N₂)ω₁`입니다. 동축 연결은 ratio=-1입니다. 위치와 속도 제약을 강체 솔버가 풀며 양쪽 질량·관성과 반력을 함께 반영합니다. 종동축의 각도를 복사하거나 예제별 각도를 계산하지 않습니다.

랙은 직선 관절과 회전 관절을 길이 차원을 가진 기어비로 연결합니다. 장착 방향과 피니언의 접촉 면으로 부호를 결정합니다. 원형 피치와 랙 중심의 법선 거리는 피치 반경+랙 두께/2여야 합니다.

기어/동축 그래프를 탐색하여 속도 비의 곱과 부호가 모순되는 폐회로를 거부합니다. 기구의 모든 가능한 과구속을 정적으로 증명하는 일반 해석기는 아닙니다. 치면 형상은 시각화이며 충돌로 톱니를 풀지 않습니다. 백래시, 기어 손실, 미끄럼, 비원형 기어 및 파손은 없습니다. 허용 토크는 측정 경고 기준이며 자동 파손 한계가 아닙니다. 축이 고정되지 않은 기어는 별도의 힌지가 필요합니다.

## 벨트와 클러치

개방 벨트의 상대 접선 속도는 `Cdot = r₁ω₁ - r₂ω₂`, 교차 벨트는 `r₁ω₁ + r₂ω₂`입니다. 두 회전체의 유효 역관성으로 충격량을 구합니다.

`Δλ = -Cdot / (r₁²/I₁ + r₂²/I₂)`

`누적 |λ| ≤ tension × friction × dt`

각 축에 `r×λ`의 각 충격량을 반대 부호로 가합니다. 제약이 양쪽 속도에 영향을 주므로 부하와 동력 전달이 존재합니다. 한계를 넘으면 상대 속도가 남아 슬립합니다. 클러치는 r₁=r₂=1인 같은 마찰 모델이며 용량의 단위는 N·m입니다. 연결 활성화를 실험 중 끌 수 있고 종동 부품에 들어오는 논리 신호로도 제어할 수 있습니다.

10회의 순차 충격량 반복을 Box2D 스텝 **후** 수행합니다. 벨트와 네이티브 기어가 함께 연결될 때 최대 한 물리 스텝의 분할 오차가 있습니다. 질량 없는 벨트, 일정 장력, 단일 접선 마찰 한계를 가정하며 실제 벨트 탄성, 원심력, 장력 분포 및 캡스턴 접촉각을 풀지 않습니다. 벨트 표면의 표시 위치는 계산된 구동축 각도에서 유도합니다. 토크 없는 장식용 애니메이션이 아닙니다.

## 크랭크·힌지·슬라이더·스프링·로프

크랭크에는 중심 고정 회전축과 r×0.72의 편심 연결점이 있습니다. 연결봉의 각 끝과 크랭크/피스톤은 RevoluteJoint로 연결합니다. 피스톤은 PrismaticJoint로 축 방향만 움직입니다. 피스톤의 운동량 변화는 관절 반력으로 입력축에 전달됩니다. 설계 시 두 힌지 포트는 80mm 이내로 겹쳐야 합니다.

WeldJoint는 상대 위치/각도를 고정합니다. 스프링은 두 연결점 사이의 질량 없는 방사형 DistanceJoint입니다. `m_eff=1/(1/m₁+1/m₂)`, `f=√(k/m_eff)/(2π)`, `ζ=c/(2√(k m_eff))`를 사용합니다. 정적 물체의 역질량은 0입니다. 안정성을 위해 **f≤12Hz, ζ≤2**로 제한합니다. 이를 넘는 강성/감쇠 설정은 그 한계에서 근사합니다. 기준 길이 0은 배치된 최초 길이를 사용합니다.

로프는 최대 길이만 제한하는 RopeJoint입니다. 느슨하면 힘을 전달하지 않습니다. 질량·굽힘·가이드 도르래·실제 로프 형상은 없으며 표시 곡선은 느슨함의 시각적 근사입니다. 스프링과 로프를 0에 가까운 길이로 배치하지 마세요.

## 캠·컨베이어

캠은 축에서 편심된 원형 충돌체로 팔로어를 실제 접촉으로 밉니다. 사용자 정의 인벌류트/자유곡선 캠은 지원하지 않습니다. 팔로어의 직선 레일과 중력이 접촉을 유지합니다.

컨베이어는 실제 관성의 회전축과 정적 접촉 지지면을 조합합니다. 접촉면의 접선 속도는 구동축 `ω×r`이며 접촉 해결 후 접선 충격량의 반작용을 축에 되돌립니다. 물체 위치를 이동시키지 않습니다. 컨베이어 벨트 자체의 유연성과 진동은 제외합니다.

## 제어 회로

기계 연결과 제어 신호를 데이터/표시 색상으로 구분합니다. switch/button, timer, delay, speed/position/contact sensor, AND/OR/NOT/controller를 제공합니다. 비순환 조합 논리는 매 120Hz 스텝에서 의존 순서로 평가해 시작 시 가짜 펄스를 방지합니다. 타이머/지연 상태는 스텝당 한 번만 갱신합니다. 피드백이 있는 회로의 되먹임 경로에는 이전 스텝 값(1/120초의 메모리)을 사용합니다.

접촉 센서는 실제 원형 sensor fixture의 접촉 목록을 읽습니다. 속도/위치 센서는 선택한 강체의 계산 결과를 읽습니다. 타이머는 주기의 첫 절반 ON이며 입력이 없으면 자체 작동합니다. delay는 입력 HIGH가 지정 시간 연속 유지될 때 ON이며 LOW에서 초기화합니다. 복수 신호가 모터에 직접 들어오면 OR로 취급합니다.

## 측정·에너지·성능

각 부품의 위치, 선/각속도, 속력, 유한차분 선가속도, 운동에너지, 모터 토크, 관절 반력, 입력 동력과 저항 부하 출력을 측정합니다. 자유 강체에 작용하는 모든 힘을 합산한 만능 힘 센서는 아닙니다. 기어 토크는 관절 반력의 크기로 표시합니다.

모터 입력은 `max(0, τ_motor×ω)/η`. 힘·토크 발생기와 선형 구동기의 양의 기계적 입력도 합산합니다. 저항 부하 출력은 `L×ω×tanh(ω/.08)`. 회생 제동은 모델링하지 않습니다. 시스템의 순간 `P_load/P_input`은 저장된 운동에너지 방출 때문에 일시적으로 100%를 넘을 수 있어 이를 정상 상태 전달 효율과 동일시하면 안 됩니다. 중력과 마우스 외부 작업은 이 전력 합계에 포함하지 않습니다.

그래프는 선택 부품의 최근 최대 600 샘플을 보관하며 10초 창의 단일 채널(RPM/토크/X/속력/운동에너지)을 보여줍니다. CSV는 보관 중인 샘플 전체를 내보냅니다. 정지하면 실험 데이터와 임시 설정을 비우고 설계를 복원합니다.

기어 경로 캐싱, 화면 밖 강체 렌더링 제외, 충돌 레이어, Sleep, bounded history/계측 데이터, 공간 분할 충돌 엔진과 React 외부의 물리 상태를 사용합니다. 상한은 파일당 1,500개 부품 / 4,000개 연결 / 5MB이며 실제 실시간 성능은 하드웨어·장면·접촉 수에 따라 달라집니다.
